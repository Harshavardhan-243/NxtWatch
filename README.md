# NxtWatch App

A responsive video streaming web application built with React.js. NxtWatch allows users to browse videos, explore trending and gaming content, search for videos, save videos, and view detailed video information.

## 📌 Features

- 🔐 User Login Authentication

- 🔥 Trending videos section
- 🎮 Gaming videos section
- 🔍 Search videos

- 📺 Watch video details
- 👍 Like and dislike videos
- 📱 Responsive design
- ❌ Not Found page
- ⚠️ Failure and retry views

## 🔑 Application Features

### Authentication

Users can log in to access the application. Protected routes prevent unauthorized users from accessing authenticated pages.

### Home

The home page displays available videos and provides search functionality.

### Trending

Users can explore currently trending videos.

### Gaming

A dedicated section allows users to browse gaming-related videos.

### Saved Videos

Users can save videos and access them later from the Saved Videos section.

### Video Details

Users can open individual videos to view their details and interact with them.

### Theme

The application supports light and dark themes for a better user experience.

## 💻 Installation

Clone the repository:

git clone https://github.com/Harshavardhan-243/NxtWatch.git

Navigate to the project directory:

cd NxtWatch

Install dependencies:

npm install

Start the development server:

npm start

The application will run locally at:

http://localhost:3000
